# Files allowed past the 600-line budget in scripts/check-sizes.sh, with the
# size each may reach. A file that grows past its number fails the check.
#
# These are the sizes on the day the budget was added. They are a ratchet, not
# an endorsement: lowering a number as a file shrinks is welcome, raising one
# needs to be a deliberate line in a diff.
#
# path                              max   why
src/app/mod.rs                      2680  # the model, the messages, `view!` and both reducers.
                                          # CLAUDE.md says those three belong together and the
                                          # reducer stays whole. Split once at 3085 and grew back;
                                          # ~200 lines of `init` wiring and session helpers could
                                          # still leave.
                                          # 2540 -> 2580 for #32: close and show hooks in `view!`, two
                                          # messages, two reducer arms and the portal result. All
                                          # of them are the kinds of thing that belong here; the
                                          # handler they call lives in `background.rs`.
                                          # 2580 -> 2650 for #18: the bottom sheet replacing the
                                          # queue sidebar in `view!`. The expanded player itself is
                                          # a component in `components/player_view.rs`.
                                          # 2650 -> 2680: the window breakpoint that lets the
                                          # navigation sidebar collapse, without which the app
                                          # cannot be tiled to half a screen.
src/components/now_playing.rs       1220  # one component, and the one whose seek arithmetic took
                                          # four rounds to get right. Splitting it is a design
                                          # question, not a move.
src/music/client.rs                  940  # one endpoint per method against one API. Long because
                                          # Apple is, and each method is short.
src/music/types.rs                   815  # the JSON boundary (rule 9). Wire types and our types
                                          # side by side is the point — they are read together.
src/app/library.rs                   700  # four collections and the catalog search, all landing in
                                          # the same list.
src/player/protocol.rs               650  # the whole sidecar contract in one file, deliberately
                                          # (rule 9). Splitting it would hide the drift it exists
                                          # to prevent.
src/components/player_view.rs        640  # the expanded player: one `view!` plus a transport built
                                          # by hand because it *moves* between two layouts, and the
                                          # refresh that `#[watch]` cannot do for widgets outside
                                          # the macro's tree. Splitting the transport out would put
                                          # its construction and its refresh in different files,
                                          # which is the pair most likely to drift.
